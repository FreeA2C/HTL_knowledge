## 6. 起動時の安定化時間

| 項目 | 目安値 | 実測 |
|------|-------|------|
| コールドスタート：出力98 %回復 | < 60 min | 9 min |
| コールドスタート：ビーム方向 < 20 µrad | < 60 min | 22 min |
| コールドスタート：ビーム位置 < 50 µm | < 60 min | 30 min |
| ホットスタート：出力98 %回復 | < 20 min | 1 min |
| ホットスタート：ビーム方向 < 20 µrad | < 20 min | 1 min |
| ホットスタート：ビーム位置 < 50 µm | < 20 min | 6 min |
| 長期出力安定度（12 h, NRMSD） | < 0.5 % | 0.13 % |
| 長期ビーム方向安定度（PtP / RMS） | < 20 µrad | 6 / 1 µrad |
| 長期ビーム位置安定度（PtP / RMS） | < 70 µm | 16 / 5 µm |

試験条件：
- コールド：全出力・6 kHz → 発振器とRAのLD停止 → チラーを運用温度 −2 °C で1時間 → 運用温度へ戻して起動（発振器LD → ML → パワーロック → RA → PP open）→ 1.5時間測定
- ホット：RAのみ停止して1時間待機 → 再起動 → 1時間測定
- 長期：全出力・6 kHz、環境温度は非安定化（試験時は約23 °C / 41 %）

FSEメモ：コールドスタート直後は数分でビーム方向が約70 µrad、位置が約600 µmまで振れてから戻る。加工位置精度が必要な作業は **電源投入から30分以上の暖機** を前提にする。
