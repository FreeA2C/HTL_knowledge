# CVD（Chemical Vapor Deposition）

## 膜強度・密着性

### 背景
- LGIT様が針のようなもので膜を擦る試験を実施（通常の評価方法ではない）
- その試験において、FHG光装置（Sculptor1820）の膜がTHG光装置（LM530A, Sculptor1416）より剥がれやすいという結果が出た
- **通常の評価では問題なし**

### 膜形成のメカニズム（確立した知識）
- CVD膜がある程度付き始めると、レーザー光はマスクに垂直に当たる
- → レーザー光の吸収による温度上昇 → **熱CVDが支配的**になる
- → レーザーパワーを上げるほど熱分解が十分に起き、**密な膜**になる

### 試験結果に対する仮説（推論ベース）
- FHGはTHGより光分解効率が高いため、空中に浮遊しているCr(CO)₆も分解してしまう可能性がある
- → **降積り**が発生しやすくなる
- → 降積りを避けるためレーザーパワーを抑えざるを得ない
- → 結果として疎な膜質になり、針擦り試験での密着強度が低下した可能性がある
- ※あくまで仮説であり、通常使用での膜品質への影響は確認されていない
- 詳細は → [laser-harmonics.md](common/laser-harmonics.md)

### 仮説に基づく対処案（未検証）
- CVDガス（Cr(CO)₆）濃度を薄めに設定して降積りを抑える
- その上でレーザーパワーを上げ、より密な膜を狙う

### 追加確認事項
- LM530AがSculptor1416より膜が強い場合、**Cr(CO)₆のメーカー違い**が影響している可能性
- → LM530Aで関東化学製Cr(CO)₆をまだ使っていないか確認が必要
